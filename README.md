## 01 · About

I like small, fast tools that respect the user: work offline, no account,
your files stay yours. Lately that means a full pixel art editor for Windows,
built end to end in TypeScript, from the drawing engine and file format to
the installer and release pipeline.

- **Now:** shipping [Raster](https://github.com/J-isaac007/raster), an open
  source pixel art editor
- **Also:** REST APIs with Express and Prisma, mobile apps with Flutter
- **Style:** test the core, keep the UI keyboard first, release often

A fast desktop editor for sprites, icons and game art. Works offline, needs no
account and keeps your work on your machine. It covers the whole sprite
workflow: draw, animate, tag loops, then export GIFs or sprite sheets with JSON
frame data that game engines read directly.

- Designed a **versioned project format** (now v4) that still opens every older file
